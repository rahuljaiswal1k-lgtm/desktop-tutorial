🔐 Portfolio Admin

Edit your portfolio content, upload images, videos, PDFs and links — changes are saved straight to GitHub and your live site updates automatically. No server needed.

One-time setup: create a GitHub access token so this panel can save changes for you.
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access → “Only select repositories” → pick desktop-tutorial.
  3. Permissions → Repository permissions → Contents → set to Read and write.
  4. Generate the token, copy it (starts with github_pat_…), and paste it below.
Stored only in this browser (localStorage). Never shared. Use “Log out” on a shared computer.
